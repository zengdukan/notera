# Notera App Icon Candidates

这组候选围绕“本地笔记保险库”设计，使用与当前界面一致的深海军蓝、品牌蓝和浅色前景。四款图标共用圆角方形底板和 1024 × 1024 画布，前景主体保持在 96 px 安全区以内。

| 候选 | 设计意象 | 字母策略 |
| --- | --- | --- |
| `vault-n` | 保险库门、锁栓与 N 字母 | 含 N |
| `folded-n` | 折叠笔记页、N 字母与加密封印 | 含 N |
| `sealed-note` | 盾牌、笔记页与锁孔 | 纯图形 |
| `locked-notebook` | 闭合笔记本与实体锁扣 | 纯图形 |

## 设计约束

- 色板：`#172B4D`、`#0C66E4`、`#1558BC`、`#F7F8F9`。
- 每款仅使用一层线性渐变，不使用文字、外部资源、模糊或投影。
- SVG 是唯一母版；PNG 由项目导出脚本生成，不手工修改。
- 本目录中的文件仅用于候选比较，不会替换当前生效的应用图标。
